# Glossary

Administrator
:   A cooperative staff member who manages the cooperative in the admin dashboard.

Agent
:   A staff member who works at one collection point, registers farmers and records deliveries.

Batch
:   The group of payments created together for one month.

B2C (Business to Customer)
:   The M-Pesa service a business uses to send money to a customer's phone. Umucyo uses it to pay farmers.

Bootstrap secret
:   The secret needed to create the very first administrator.

Callback (webhook)
:   A request Safaricom sends to Umucyo to report the result of a payment.

Collection point
:   A place where farmers bring tea to be weighed.

Cooperative
:   The tea cooperative that owns all the data in its account.

Daraja
:   Safaricom's developer platform for M-Pesa.

Delivery (produce record)
:   One farmer's tea delivery: its weight, status and amount owed.

Gross weight
:   The weight of the delivered tea leaves, in kilograms.

Migration
:   A versioned change to the database structure, written with Alembic.

Mock mode
:   A payment mode for local work that never contacts Safaricom.

OTP (one-time password)
:   The 6-digit code emailed at login.

Sandbox
:   Safaricom's test environment. It simulates payments; no real money moves.

USSD
:   Short menu sessions on any mobile phone, started by dialling a code such as `*123#`.

Weighing device
:   A registered scale at a collection point.
